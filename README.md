# A Couple of Excel Projects for Data Analytics

This repository contains the Excel projects I completed while developing my data analytics skills. These projects use Excel to clean, analyze, and visualize real-world data, with a focus on extracting useful insights and presenting them clearly.

## Salary Dashboard

This interactive salary dashboard was created to explore salaries across different data-related job titles, locations, and employment types. The dashboard allows users to compare salary trends and better understand the data job market.
